╔════════════════════════════════════════════════════════════════════════════════╗
║                         PERMISSION ARCHITECTURE                               ║
╚════════════════════════════════════════════════════════════════════════════════╝

USER
 └─ SYS_Users.ROL_ID → Links to Role
                        │
                        ▼
                    SYS_Roles
                    (Role Definition)
                    Example: "HR Manager"
                        │
                        ▼
                    SYS_Role_Permissions
                    (Role has many permissions)
                    Example: "HR Manager has HRM_VIEW_EMPLOYEES"
                        │
                        ├─ PRM_ID = "HRM_VIEW_EMPLOYEES"
                        ├─ SRP_Is_Allowed = TRUE
                        ├─ SRP_Scope = "ALL"
                        │   └─ ALL = Can see all records
                        │   └─ OWN = Can see only own records
                        │   └─ DEPARTMENT = Can see department records
                        │
                        └─ SRP_Constraints = (additional rules)
                           Example: "Can only edit own department"


Example Permission Chain:

User "mkhoraiby"
    │
    ├─ Role: "ROLE_HR_MANAGER"
    │   │
    │   └─ Permissions:
    │       ├─ HRM_VIEW_EMPLOYEES (Scope: ALL)
    │       ├─ HRM_CREATE_EMPLOYEE (Scope: ALL)
    │       ├─ HRM_EDIT_EMPLOYEE (Scope: ALL)
    │       ├─ HRM_DELETE_EMPLOYEE (Scope: OWN)
    │       ├─ HRM_VIEW_ATTENDANCE (Scope: ALL)
    │       └─ HRM_MANAGE_LEAVE (Scope: ALL)
