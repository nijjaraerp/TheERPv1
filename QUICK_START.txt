⏱️  ESTIMATED TIME: 30 minutes to full deployment

════════════════════════════════════════════════════════════════════════════════
STEP 1: CREATE GOOGLE SHEET (2 minutes)
════════════════════════════════════════════════════════════════════════════════

1. Go to: https://drive.google.com
2. Click: + New → Google Sheets → Blank spreadsheet
3. Name it: TheERPv1
4. Copy the SHEET ID from URL (between /d/ and /edit)
   Example: docs.google.com/spreadsheets/d/[SHEET_ID]/edit
5. KEEP THIS TAB OPEN

════════════════════════════════════════════════════════════════════════════════
STEP 2: OPEN APPS SCRIPT (1 minute)
════════════════════════════════════════════════════════════════════════════════

1. In your Google Sheet, click: Extensions → Apps Script
2. New tab opens with code editor
3. Delete the default code
4. CREATE NEW SCRIPT FILES:

   File 1: Click + → Script → Name: "Setup"
   File 2: Click + → Script → Name: "Code"
   File 3: Click + → Script → Name: "Utils"
   File 4: Click + → Script → Name: "Seed_Data"

════════════════════════════════════════════════════════════════════════════════
STEP 3: COPY CODE INTO EACH FILE (5 minutes)
════════════════════════════════════════════════════════════════════════════════

📄 Setup.js → Copy into "Setup" file → Save (Ctrl+S)
📄 Code.js → Copy into "Code" file → Save (Ctrl+S)
📄 Utils.js → Copy into "Utils" file → Save (Ctrl+S)
📄 Seed_Data.js → Copy into "Seed_Data" file → Save (Ctrl+S)

Wait for each file to save completely before moving to the next.

════════════════════════════════════════════════════════════════════════════════
STEP 4: INITIALIZE DATABASE (3 minutes)
════════════════════════════════════════════════════════════════════════════════

1. In Apps Script, click the function dropdown (top left)
2. Select: "setupERPSystem"
3. Click the PLAY (▶) button
4. Click AUTHORIZE when prompt appears
5. Select your Google account
6. Click ALLOW
7. Wait for completion (should see success message)

✅ Check: Go to your Google Sheet → You should see 35 new sheet tabs!

════════════════════════════════════════════════════════════════════════════════
STEP 5: POPULATE INITIAL DATA (2 minutes)
════════════════════════════════════════════════════════════════════════════════

1. In Apps Script, select: "seedAllData" from function dropdown
2. Click PLAY button
3. Wait for completion

✅ Check: Click SYS_Users sheet → You should see demo users with data

════════════════════════════════════════════════════════════════════════════════
STEP 6: DEPLOY AS WEB APP (5 minutes)
════════════════════════════════════════════════════════════════════════════════

1. In Apps Script, click: "Deploy" (top right)
2. Click: "New deployment"
3. Select type: "Web app"
4. Keep: Execute as = (your email)
5. Set: Who has access = "Anyone"
6. Click: "Deploy"
7. ⭐ COPY THE DEPLOYMENT URL ⭐
   (Should look like: https://script.google.com/macros/d/abc123/userweb)

════════════════════════════════════════════════════════════════════════════════
STEP 7: ADD HTML FILES (3 minutes)
════════════════════════════════════════════════════════════════════════════════

1. In Apps Script, click: + → HTML
2. Name it: "Login"
3. Copy content from Login.html file
4. Find line: SCRIPT_URL: 'YOUR_SCRIPT_URL_HERE'
5. Replace with your deployment URL from Step 6
6. Example:
   SCRIPT_URL: 'https://script.google.com/macros/d/abc123/userweb'
7. Save (Ctrl+S)

════════════════════════════════════════════════════════════════════════════════
STEP 8: OPEN THE SYSTEM (1 minute)
════════════════════════════════════════════════════════════════════════════════

1. In Apps Script, click: Deploy → Select deployment
2. Click the deployment URL in the modal
3. 🎉 YOU SHOULD SEE THE LOGIN PAGE!

════════════════════════════════════════════════════════════════════════════════

TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

❌ Sheet not found error
   → Make sure sheet is named exactly: TheERPv1

❌ Script URL invalid
   → Get the deployment URL from Apps Script Deploy menu
   → Paste exact URL into Login.html SCRIPT_URL

❌ Login doesn't work
   → Check SYS_Users sheet for the user (mkhoraiby)
   → Make sure USR_Is_Active = TRUE

❌ Can't run setupERPSystem
   → Make sure all .js files are saved
   → Check for red X icons (syntax errors)
   → Try with simpler Google account (not workspace admin)
